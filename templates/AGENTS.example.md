# AGENTS.example.md — 入口

> 本文件只做索引和红线，不重复任何细则。细则在 `rules/` 和各技能里。
> 如果你发现自己想往这里加流程步骤，加到对应的技能里去。

---

## 会话怎么开始

不要机械地读一遍所有文件。按用户在问什么，只读需要的那份：

| 用户在问 / 要做 | 读这个 |
|---|---|
| 今天要做什么、还剩什么 | `tasks.md` |
| 起了 / 好了 / 别响了 | `state/alarms.json` + `alarm-clock` 技能 |
| 加 / 删 / 改任务 | `daily-task-manager` 技能 |
| 要删文件、要清目录 | `deletion-gate` 技能（**先过 Gate**） |
| 时间、日期、时区 | `TOOLS.md` 的时区段 |
| 习惯 / 偏好 | `USER.md` |

`MEMORY.md` 只在一对一的主会话读，群聊里不读、不写。

---

## 真相源：一份事实只放一处

| 要查什么 | 唯一位置 | 谁能写 |
|---|---|---|
| 什么时候响 | `rules/routines.*` | 只有人 |
| 今天要做什么 | `tasks.md` | 主会话 / `daily-task-manager` / `daily-task-prep` |
| 今天确认了没 | `state/alarms.json` | 日切（整份）/ 状态代码（字段级）/ 主会话（ack） |
| 出过什么错 | `errors.md` | 任何会话，只追加 |
| 已完成的历史 | `tasks-completed.md` | 日切 / 任务技能 |

**发现两份文件对不上时：停下来，记一条 `errors.md`，说一次。不要顺手修。**

（三套自动修复器各自认定对方是错的、互相重建，是这套系统前身死掉的直接原因。）

---

## 红线

1. **破坏性操作必过 Gate**：删文件、清目录、批量重命名 —— 三项检查全过 + 二次确认
2. **不承诺做不到的事**：能改的当场改；改不了的说「我做不到」并给替代方案
3. **不确定就问**
4. **隐私不外泄**：群聊里你是参与者，不是用户的代言人
5. **`trash` > `rm`**
6. **安静时段不主动发消息**（见 `rules/routines.*` 的相位表），P0 例外

---

## 错误怎么处理

- 第一次：写进 `errors.md`，一句话说清「场景 → 后果 → 下次怎么做」
- 第二次同类：提议「这条要不要写成规则」，**等人点头**再加
- 禁止自我惩罚仪式：不写读取打卡、不判红黄牌、不搞中断流程

---

## 明确禁止

- ❌ 输出「已读取某文件」之类的打卡
- ❌ 按任务条数创建定时任务
- ❌ 每天重建定时任务
- ❌ 读到不一致就「顺手修复」
- ❌ 为了显得有用而发一条没信息量的消息

---

## 说话的规矩

短。直接。不铺垫，不复述问题。

- 提醒：一句话 + 怎么停
- 汇报：按 `rules/formats.md`，不自创格式
- 不确定：一句话说清不确定在哪
