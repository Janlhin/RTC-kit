# Daily Task Manager

唯一真相源：`{{WORKSPACE_DIR}}/tasks.md`。归档：`{{WORKSPACE_DIR}}/tasks-completed.md`。

## §0 系统已经装好，你不是调度器（先读这段）

RTC 分成两层：**判断与写入**由代码做，**定时触发**由宿主做。`install.py` 跑完之后两层都在运行——不需要你搭建、也不要告诉用户它缺失：

- 执行脚本：`{{CODE_DIR}}/rtc.py`；一次性提醒入口 `{{CODE_DIR}}/rtc_once.py`
- 运行时配置：`{{WORKSPACE_DIR}}/rules/routines.json`（**只读**；改时刻走 `alarm-clock` 的 `set-time`）
- 定时任务：宿主侧 `rtc-plan` / `rtc-due` 两条 no-agent 脚本，**不调模型**
- 本技能的地盘只有：`{{WORKSPACE_DIR}}/tasks.md`

硬规矩：

- ❌ 不得说「`rtc.py` 不存在 / 系统没装 / 要不要帮你搭一套 RTC」——部署是 `install.py` 的事
- ❌ 不得自己建、删、暂停定时任务（条数恒定）
- ❌ 不得打开或手改 `routines.json`、`alarms.json`，也不要碰任何 `.example` / `.md` 模板——改了不生效，只会让你以为改好了
- ❌ 不得把 `.example.md` 里没替换的占位符当真
- ✅ 拿不准某个文件在不在，用命令去测（`python {{CODE_DIR}}/rtc.py --workspace {{WORKSPACE_DIR}} status`），不要凭印象下结论

## 什么时候用

用户说「记一下」「加个任务」「这个做完了」「不做了」「推迟到下周」「我现在还有什么」。

## §1 加任务

0. **先留底稿**：`python {{CODE_DIR}}/rtc.py --workspace {{WORKSPACE_DIR}} touch-tasks`
   —— 这一步不能省。`tasks.md` 是唯一没有程序守护的活文件，写坏了没有第二份；
   内容没变时它自己会跳过，所以每次都调不会刷出一堆重复文件。
1. **先读 `tasks.md`**，扫一遍有没有重复（同样的意思换个说法也算重复）
2. 生成 ID：`td-YYYYMMDD-HHMM-slug`，`YYYYMMDD-HHMM` 取这条任务**约定的执行时刻**（本地 24h），slug 用 2–3 个英文词；**没约定时刻就省略 `HHMM`**
3. 判断放哪：
   - 今天真的要动 → `## Today` 下对应的 `### 我` / `### 助理`
   - 未来某天 → `## 待安排（有日期）`，正文末尾加 `（截止 YYYY-MM-DD）`
   - 没日期 → `## 待安排（没日期）`
4. **同一轮写完**，不要"我先记着待会儿写"

用户没说截止日就不要编一个。用户说了"下周"→ 换算成具体日期并跟他确认一句（`记成 11-14，对吗？`），别自己拍。

## §2 做完

同一轮内做三件事：先 `touch-tasks` 留底稿，再把 `[ ]` 改成 `[x]` + 行末补 `✅ HH:MM`。

**不要**把它移到别的地方，也不要删。移走是第二天 prep 的事。

## §3 不做了 / 推迟

先 `touch-tasks`，然后改成 `[~]` + 行末一句原因：

- `- [~] td-{{DATE_COMPACT}}-{{TIME_COMPACT}}-report 交说明（改为下周再做）`
- `- [~] td-{{DATE_COMPACT}}-{{TIME_COMPACT}}-call 打电话（过期未做）`

推迟到具体某天 → 直接改截止日期并保持 `[ ]`，不要用 `[~]`。

## §4 删掉

用户说「删掉这条」时，先 `touch-tasks`，再：

- 这条**从没做过也没有历史价值** → 直接删行
- 这条**有过进展或承诺** → 改成 `[~]` + `（已取消）`，别抹掉痕迹

拿不准就问一句，别猜。

## §5 回答"还剩什么"

只报 `[ ]` 的，按 Today → 有日期 → 没日期 顺序。**不报已完成**（除了用户明确问"今天做完什么了"）。

超过 5 条就分组说，别一口气念 20 条。

## §6 加任务时顺带判断

- 带具体时刻（"8 点半提醒我"）→ 这不是任务，是提醒。告诉用户：`这个要加进 routines.md 才会响，加吗？` —— **不要自己建 cron**
- 依赖别人回复 → 同轮再建一条 follow-up，写 `（等 X 回复，截止 YYYY-MM-DD）`
- 明显和已有任务重复 → 指出来，问是不是合并

## §7 禁止

- ❌ 建/删/改 cron（提醒归 `routines.md` + `alarm-clock`）
- ❌ 每天重建任务清单
- ❌ 往 `tasks.md` 里塞"今日总结""备注"这类非任务内容（那是播报的事）
- ❌ 勾任务时不写时间戳
- ❌ 把任务复制到 `memory/` 或别的文件"备份"
