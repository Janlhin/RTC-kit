# NLU L0/L1：确定性中文时间解析

> 层级定位：NLU 三级漏斗 —— **L0** 正则 / 封闭词表、**L1** 本地确定性时间计算、
> **L2** 模型理解。本轮落地只做 L0/L1：不接 LLM、零模型、运行时零第三方依赖。
> 判定链路（`plan` / `due` / tick）仍然是纯代码，不经过本模块。

## 1. 边界与依赖纪律

- 解析器在 `code/rtc_nlu.py`，只被交互入口 `code/rtc_once.py` 与事件写命令层
  `code/rtc_event_cmd.py`（`create --when`）import；事件命令层用函数内惰性 import，
  模块加载期不拉解析器。
- `rtc_core`、`rtc_plan`、`rtc_due` 及判定链路模块**不得**依赖解析器；该约束有
  双重机器判据（见 `code/tests/test_nlu.py`）：
  - 静态 AST 扫描：除 `rtc_once.py` / `rtc_event_cmd.py` 外，任何 `code/*.py` 都不允许 import `rtc_nlu`；
  - 运行时子进程：全新解释器加载核心判定链，`sys.modules` 里不得出现 `rtc_nlu`。
- 解析器反向也不依赖核心模块，前端翻译层可独立单测。

## 2. 确定性口径

- **现在时刻必须注入**：`parse_phrase(phrase, now, tz)` 的 `now` 是 tz-aware datetime；
  模块内部不调用 `datetime.now` / `date.today` / `utcnow`（测试用 AST 扫描钉死）。
- 同一短语 + 同一 `now`，多次解析结果逐字段一致；不允许读系统时间做隐式兜底。
- 时区一律用调用方给出的 IANA `tzinfo`（`zoneinfo`）；日级运算按本地墙钟，
  相对时长先落到 UTC 瞬时再加，避免 DST 边界上按墙钟重算偏移导致瞬时漂移。

## 3. 支持范围（封闭词表）

### 3.1 日锚点

| 类别 | 短语示例 | 口径 |
|---|---|---|
| 相对天数 | 今天 / 明天 / 后天 / 大后天 / 昨天 | 相对今天的日历日偏移 |
| 数字天数 | `3天后`、`5天以后` | 相对今天 +N 天，时刻继承 now 的时分 |
| 本周 / 下周 | 本周三、下周一、这周六 | 周一为一周起点；「下周 X」= 下一个自然周的周 X |
| 裸周几 | 周三、周五 | 本周内未到取本周，已过顺到下周；今天正好是该周几就取今天 |
| 月内日期 | 这个月20号、本月5号 | 当月给定日 |
| 下月日期 | 下个月1号、下月15号 | 下月给定日；月末不被天数夹住（1/31 的「下个月1号」= 2/1） |

### 3.2 时刻

| 类别 | 短语示例 | 口径 |
|---|---|---|
| 时段 + 小时 | 凌晨1点、早上7点、上午11点、中午12点、下午3点、晚上8点 | 下午 / 晚上 小于 12 点拨 +12；上午 / 凌晨 12 点归 0；中午不拨 |
| 分钟 | 三点半、两点十分、7:05 | 「半」= 30 分；中文 / 阿拉伯数字都认 |
| 相对时长 | 半小时后、一个半小时后、2小时后、20分钟后 | 在注入 now 的瞬时上叠加 |

### 3.3 组合

日锚点 + 时刻可组合，如「明天下午三点」「下周三下午3点」「3天后早上9点」。

**无时刻时的默认口径**（写死，不临场猜）：

- 纯天数偏移（今天 / 明天 / N 天后）：继承 now 的当前时分；
- 周 / 月锚点：默认上午 09:00。

### 3.4 周期表达（`recurring=True` 开关）

`parse_phrase(..., recurring=True)` 时，封闭词表内的周期形状产出
`kind="recurring"` + RFC 5545 `rrule` 字符串 + 首个 occurrence 的 `dtstart`：

| 类别 | 短语示例 | RRULE | DTSTART 口径 |
|---|---|---|---|
| 每日 | 每天早上八点、每日 | `FREQ=DAILY` | 今天槽位未过取今天，已过取明天 |
| 每周 | 每周三晚上八点、每周一三五 | `FREQ=WEEKLY;BYDAY=WE` / `FREQ=WEEKLY;BYDAY=MO,WE,FR` | 最近命中的周几；多日集合取最早命中日 |
| 每月 | 每月1号、每月31号 | `FREQ=MONTHLY;BYMONTHDAY=1` | 下一个该日号；跳过没有该日的月份（如 2 月无 31 号） |
| 每年 | 每年11月5日 | `FREQ=YEARLY;BYMONTH=11;BYMONTHDAY=5` | 下一个周年；今年已过取明年 |
| 每 N 周期 | 每3天、每2周、每4个月 | `FREQ=DAILY;INTERVAL=3` / `FREQ=WEEKLY;INTERVAL=2` / `FREQ=MONTHLY;INTERVAL=4` | 同基础频率口径；`INTERVAL=1` 省略 |

- 周期表达缺时刻默认 **09:00**；`rrule` 直接存 RFC 5545 字符串，不自造 DSL。
- **开关默认关闭**（`recurring=False`）：`rtc_once.py` 一次性入口仍是既有契约，
  周期短语按既有契约拒绝；事件命令层 `create --when` 以 `recurring=True` 解析，
  落库映射见行为契约 §5d.1；occurrence 展开仍由 P3 接线。

## 4. 不支持清单（明确拒绝，不偷偷降级）

下列表达即使打开周期开关也表达不了，解析器抛 `UnsupportedExpression`，入口在
stderr 给出「现有契约不支持：<原因>」，**不**硬塞进某个单次时刻、**不**静默改写。

| 表达类型 | 示例 | 原因 |
|---|---|---|
| 月末 / 工作日规则 | 每月最后一个工作日复盘 | 需 BYSETPOS + 工作日历 |
| 第 N 周定位 | 每年第 3 周的周三 | 需 BYSETPOS 定位周几 |
| 工作日 / 节假日 | 工作日提醒、节假日 | 依赖工作日历 |
| 隔周 / 每两周 | 隔周锻炼、每两周 | 间隔周数的中文形态未收；`每 N` 仅认阿拉伯数字 |
| 词表外混杂文本 | 嘀嘀嗒嗒 | 抛 `NluError`「无法识别」，入口非零退出 |

> 注：早期整类周期表达（每年、每周一三五、每天几点、每月 1 号）均在此列；
> P4 已把基础天 / 周 / 月 / 年与每 N 周期收进 §3.4，本表仅剩上述需工作日历 /
> BYSETPOS 的形状（T-014 已收窄）。

## 5. 退出码选择

`rtc_once.py` 既有拒绝路径统一返回 **2**（`fail()` 出口，见脚本内说明）。NLU 的
「不支持 / 无法识别」复用这条既有出口，返回 2，**不新造码值**。核心契约退出码
集合仍是 0 正常 / 2 状态冲突 / 3 校验失败 / 4 无匹配窗口；本模块不改动该集合。

## 5b. 既有 HH:MM 路径的「今天」时区基准

`HH:MM` 入口未改解析规则与参数；但其缺省日期原先取进程本地 `date.today()`。
在 UTC 运行机（如 CI）上跨午夜后，这个本地日期会早于 plan 按工作区时区算出的
「今天」，刚登记的一次性提醒会被 plan 的过期清理误删。本轮把缺省日期改为按
**时刻表时区**取当天（与 plan 的 `today` 同一条基准）；显式 `--date` 行为不变。

## 6. 已知边界（本轮不做，登记进 TASKS 待补）

- 周期写路径：`create --when` 已把解析结构落进影子账本（`start` / `end` / `rrule`）；
  按 occurrence 走 plan/due/ack 的展开联动仍由 P3 接线，本层不产出展开实例。
- 剩余周期形状：工作日历、BYSETPOS、相对月末、第 N 周定位、隔周 / 每两周，见 §4（T-014）。
- 裸周几 / 月锚点缺时刻时的默认 09:00：后续可让入口向用户确认，而非固定默认（T-015）。
- 春切空档 / 秋切重复的歧义本地时间：按 `zoneinfo` 默认 `fold=0` 解析，见
  [timezone.md §6](timezone.md)；本轮不做显式消歧。
- L2 模型兜底：词表外的开放表达仍走宿主模型层，不在本模块内调用。
