# 时区模型（#91）

RTC 的行程按**目的地时区**排；时间模型存 IANA 时区名，旧配置的固定偏移继续可读。

## 1. 配置里的两个字段

| 字段 | 含义 | 优先级 |
|---|---|---|
| `timezone` | IANA 时区名，如 `Asia/Shanghai`、`America/New_York`，跟随夏令时 | **首选** |
| `tzOffset` | 旧格式固定偏移 `+HH:MM`，不跟随夏令时 | 缺 `timezone` 时的兼容回退 |

解析回退链（`rtc_core.resolve_tz`）：

1. `timezone` 是可加载的 IANA 名 → 用 `zoneinfo.ZoneInfo`（跟随 DST）；
2. 否则 `tzOffset` 是 `+HH:MM` → 固定偏移，行为与改造前逐字节一致；
3. 两者都缺 → 默认固定偏移 `+08:00`。

旧配置（只有 `tzOffset`、没有 `timezone`）必须照常跑通，不许报错；只有两个都缺时才判配置非法。

## 2. 依赖边界

- 运行时只用 Python 标准库 `zoneinfo`，**不引入任何第三方时区库**。
- `tzdata`（IANA 数据库打包）只出现在 **dev/test 依赖与 CI 测试层**，不进运行时依赖。
- Linux / macOS 一般自带系统时区库；Windows 上 Python 不带 tzdata，靠测试层安装 `tzdata` 补。

### Windows 缺 tzdata 时的回退（明确限制，不偷偷吞掉）

如果环境里找不到时区键（缺 tzdata，或写了不存在的时区名）：

- 不抛栈、不崩；
- 回退到 `tzOffset` 固定偏移；连 `tzOffset` 也没有就回退默认 `+08:00`；
- 同时往 `NOTICES` 留一条提示（plan / brief 播一次），写明「哪个时区不可用、回退到了哪个偏移」。

## 3. .ics 导出的时区口径

`.ics` 绝不输出**浮动时间**（无 TZID、无 `Z` 的裸本地时间）。每条事件按下面三选一：

| 情形 | 写法 |
|---|---|
| 瞬时是 UTC（偏移 0） | `DTSTART:20261118T070000Z` |
| 状态带可加载的 IANA 时区 | `DTSTART;TZID=America/New_York:20260308T090000`，并在日历流里附 `VTIMEZONE` 块 |
| 旧固定偏移账本 / 缺时区标识 | 换算成 UTC 瞬时，用 `Z` 后缀输出 |

## 4. DST worked example：America/New_York（2026）

纽约 2026 年两次切换（EST = UTC-5，EDT = UTC-4）：

| 时刻（UTC） | 纽约墙钟 | 偏移 | 说明 |
|---|---|---|---|
| 2026-03-07 12:00Z | 07:00 EST | `-05:00` | 春切之前 |
| 2026-03-09 12:00Z | 08:00 EDT | `-04:00` | 2026-03-08 02:00 拨快到 03:00，春切之后 |
| 2026-10-31 12:00Z | 08:00 EDT | `-04:00` | 秋切之前 |
| 2026-11-02 12:00Z | 07:00 EST | `-05:00` | 2026-11-01 02:00 拨慢到 01:00，秋切之后 |

墙钟 → 瞬时往返：纽约 2026-03-08 09:00（EDT, `-04:00`）= UTC 13:00。

## 5. 双时区 worked example

一份时刻表只有一个时区；跨时区行程按**目的地时区**排。同一瞬时在两个时区的墙钟对照（2026-11-18，纽约 EST `-05:00`，上海 `+08:00`，相差 13 小时）：

| 上海墙钟 | UTC 瞬时 | 纽约墙钟 |
|---|---|---|
| 2026-11-18 07:00 +08:00 | 2026-11-17 23:00Z | 2026-11-17 18:00 EST |
| 2026-11-18 21:00 +08:00 | 2026-11-18 13:00Z | 2026-11-18 08:00 EST |

换算永远先落到 UTC 瞬时，再转到目标时区；换时区不漂瞬时。

## 6. 已知边界（本轮不做）

- **不存在 / 歧义本地时间**：春切空档、秋切重复的墙钟，按 `zoneinfo` 默认 `fold=0` 解析；本轮不做显式的歧义消歧规则。
- **重复提醒保留墙钟**：周期窗口按所在时区的本地墙钟排，不锁定成绝对 UTC 瞬时。
- **显示时区 = 事件时区**：一份时刻表一个时区；不在同一事件里混排两个时区。
- **国家选择**：选国家只是挑 IANA 名的 UI 快捷方式，本轮不做国家映射表。
